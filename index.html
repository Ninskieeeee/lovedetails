Caesar Cipher Instructions

  1. Type your message in the Cipher Message box.
  2. Enter a shift number.
  3. Click Encipher.
  4. Click Decipher.

How Caesar Cipher Works

The Caesar Cipher shifts letters forward or backward in the alphabet using a shift number.

Example (Shift 3): A → D, B → E, C → F.

Deciphering shifts letters backward using the same number.

Hash Generator Instructions

  1. Type your message in the Hash Message box.
  2. Click Generate Hash.
  3. The system will create a SHA-256 hash.
  4. Hashing is one-way and cannot be decrypted.

How Hashing Works

Hashing converts your message into a fixed-length string using SHA-256.

The same input always produces the same hash.

Even a small change in the message creates a completely different hash.

Hashing is one-way and cannot be reversed.
